# 교육기관 바로가기 공식 로고 출처

이 폴더의 파일은 각 기관 공식 웹사이트가 실제 사용하는 자산의 원본 보관본이다.
Google Apps Script HTML Service는 프로젝트의 임의 정적 이미지 파일을 URL로 직접 제공하지 않으므로, 배포 화면에서는 동일한 공식 원본 URL을 사용한다.

| 파일 | 공식 출처 | 사이트 내 용도 |
| --- | --- | --- |
| `jge-header-logo.png` | `https://www.jge.go.kr/images/template/T0001/layout/logo.png` | 전남광주통합특별시교육청 헤더 로고 |
| `jge-symbol-only.png` | `https://www.jge.go.kr/main/cf/fileDownload.do?fileKey=eb6a23c24ebc65ed239fb7971739acc7` | 교육청 공식 CI 페이지의 심벌마크 전용 PNG |
| `yeosu-header-logo.png` | `https://ysed.jge.go.kr/images/web/ysed/common/logo.png` | 여수교육지원청 헤더 로고(동일 심볼 확인용 원본 보관) |
| `jnstudy-favicon.ico` | `https://www.jnstudy.kr/resource/image/favicon.ico` | 전남교육연수포털 favicon |
| `star-favicon-48.png` | `https://star.moe.go.kr/resource/tmpl/assets/images/favicon/favicon-48x48.png` | 학교생활기록부 종합지원포털 48px favicon |
| `stas-header-logo.png` | `https://stas.moe.go.kr/assets/ptl/images/logo_stas.png` | 학생평가지원포털 헤더 로고 |

전남광주통합특별시교육청과 여수교육지원청은 같은 공식 심볼을 사용한다. 배너에서는 두 카드에 교육청 공식 CI 페이지가 제공하는 심벌마크 전용 PNG를 공통 사용하며, 기관명과 이동 URL만 각각 유지한다.
